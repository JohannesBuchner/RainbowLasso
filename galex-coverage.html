GALEX upper limits#

For sources without any GALEX detection, the pipeline estimates a NUV upper limit from the GALEX AIS coverage and the Milky Way dust column. This is a separate mechanism from the GALEX catalog match (which provides no upper limits at all, see GALEX); no FUV upper limit is provided.

Coverage table#

galex_ais_ctrs.fits contains the center positions of the GALEX AIS tiles (columns RAfdeg, DEfdeg).

galexebv.py adds the SFD Milky Way E(B-V) at each tile center (via the dustmaps package) and writes galex_ais_ctrs_ebv.fits:

galex_ais_ctrs_ebv.fits: galexebv.py galex_ais_ctrs.fits
	python3 $<

Upper limit per position#

Each input position is matched to the nearest GALEX AIS tile center within 0.56 degrees (1980 arcsec, the tile diagonal). The NUV flux limit is scaled up with the Galactic extinction towards the tile center:

%_GALEX_UL.fits: %_coords.csv galex_ais_ctrs_ebv.fits
	# search within 0.56 degrees
	stilts tmatch2 out=$@ matcher=sky find=best params=1980 \
		in1=$< values1="RA Dec" \
		in2=galex_ais_ctrs_ebv.fits values2="RAfdeg DEfdeg" \
		ocmd='addcol NUV_fluxlim "0.02 * pow(10, EBV_min * 1.35)"'
		#ocmd='addcol NUV_maglim "20.8 - 8.621 * EBV_min"' \
		#ocmd='addcol NUV_fluxlim "3.631 * pow(10, (NUV_maglim - 22.5) / 2.5)"'

The rule computes NUV_fluxlim = 0.02 * 10^(EBV_min * 1.35) (mJy), i.e. the base NUV sensitivity (0.02 mJy) degraded by the dust transmission. In the final merge (see Output files), sources without a GALEX detection get NUV = 3 * NUV_fluxlim (a 3 sigma upper limit, negative error convention) and NUV_err = -NUV.

References#

  • Schlegel, Finkbeiner & Davis 1998 (ApJ 500, 525): the SFD Milky Way dust maps that galexebv.py queries (via the dustmaps package, Green 2018).

  • Bianchi, Shiao & Thilker 2017 (GUVcat_AIS): the AIS tile grid that the coverage table galex_ais_ctrs.fits is built from.
