SDSS (optional)#

Catalog: SDSS DR16 (PhotoObj), queried through SciServer CasJobs (requires a sciserver account).

Wavelengths: u, g, r, i, z.

Setup#

To use SDSS fluxes, put a sciserver username and password into a text file ~/.config/sciserver/login.txt:

username:password

Matching and fluxes#

%_SDSS.fits: fetchSDSS.py %.fits
	python3 $^ $@ || stilts tpipe in=$^ out=$@ cmd='keepcols "id"'

The nearest source within 1 arcsec is retrieved (fetchSDSS.py). The photometry flags are decoded with the SDSS flag names, and the usable flags are computed (see fetchSDSS.py).

In the final %_withSDSS.fits file:

%_withSDSS.fits: %.fits %_SDSS.fits
	stilts tmatch2 out=$@ join=all1 \
		in1=$*.fits suffix1= values1=id \
		in2=$*_SDSS.fits suffix2=_SDSS values2=id \
		fixcols=all matcher=exact \
		ocmd='addcol u_sdss "pointlike?psfMag_u_SDSS:aper_u_SDSS"' \
		ocmd='addcol u_sdss_err "pointlike?psfMagErr_u_SDSS:aper_u_err_SDSS"' \
		ocmd='addcol g_sdss "pointlike?psfMag_g_SDSS:aper_g_SDSS"' \
		ocmd='addcol g_sdss_err "pointlike?psfMagErr_g_SDSS:aper_g_err_SDSS"' \
		ocmd='addcol r_sdss "pointlike?psfMag_r_SDSS:aper_r_SDSS"' \
		ocmd='addcol r_sdss_err "pointlike?psfMagErr_r_SDSS:aper_r_err_SDSS"' \
		ocmd='addcol i_sdss "pointlike?psfMag_i_SDSS:aper_i_SDSS"' \
		ocmd='addcol i_sdss_err "pointlike?psfMagErr_i_SDSS:aper_i_err_SDSS"' \
		ocmd='addcol z_sdss "pointlike?psfMag_z_SDSS:aper_z_SDSS"' \
		ocmd='addcol z_sdss_err "pointlike?psfMagErr_z_SDSS:aper_z_err_SDSS"' \

the flux extraction is adapted to the source type:

  • for point sources: the PSF magnitudes (psfMag_*),

  • for extended sources: the aperture magnitudes (aper_*).

Output columns#

u_sdss, g_sdss .. (and _err): magnitudes and errors in the %_withSDSS.fits file.

References#

  • York et al. 2000 (AJ 120, 1579): the SDSS survey.

  • SDSS photometric flags documentation: the flag names decoded by fetchSDSS.py.

  • SDSS DR16 PhotoObj schema: the catalog columns (psfMag, aper magnitudes).
