NOAO Data Lab#

Astro Data Lab hosts the Legacy Survey, VISTA Hemisphere Survey, UKIDSS and Euclid catalogs that RainbowLasso queries.

Setup#

Data Lab requires a free account. Log in once:

datalab login

The credentials are stored in your home directory and shared between environments.

How the pipeline queries Data Lab#

For each survey, the Makefile follows the same pattern (shown here for VHS; the segments are regenerated with python3 makefilesegments.py, see Makefile segments for the documentation):

%_VHS_noirlab.fits: %_coords.csv
	datalab mydb_import --table=rblvhs --data=$^ --append=False
	datalab query --sql="select id, vhs.* from vhs_dr5.vhs_cat_v3 as vhs, mydb://rblvhs WHERE q3c_join(ra, dec, vhs.ra2000, vhs.dec2000, 1./60/60)" ${DLLONGQARGS} --out=mydb://rblvhsout
	datalab query --sql="select * from mydb://rblvhsout" ${DLLONGQARGS} --fmt=fits --out=$@
	stilts tpipe in=$@ ifmt=fits omode=count
	datalab mydb_drop --table=rblvhs || true
	datalab mydb_drop --table=rblvhsout || true

  1. The input catalog is reduced to id, RA, DEC columns (%_coords.csv, with stilts).

  2. The coordinates are uploaded into a temporary mydb table (mydb_import).

  3. A SQL query cross-matches the uploaded coordinates against the survey table with q3c_join within 1 arcsec (the survey source closest to each input position is selected). For neighbour queries (%_LS_neighbours_noirlab.fits), a 20 arcsec radius is used.

  4. The result is fetched as a FITS file (--fmt=fits).

  5. The temporary mydb tables are dropped again.

Tables used#

survey

table

bands

Legacy Survey

ls_dr10.tractor + ls_dr10.apflux

g, r, i, z, W1, W2, W3, W4 (see Legacy Survey (optical))

VHS

vhs_dr5.vhs_cat_v3

Y, J, H, Ks (see VISTA Hemisphere Survey (VHS))

UKIDSS

ukidss_dr11plus.lassource

Y, J, H, K (see UKIDSS (near-infrared))

Euclid Q1

euclid_q1.object

VIS, NISP (see Euclid Q1 (optional))

For the Legacy Survey, the tractor photometry is joined with the aperture flux table ls_dr10.apflux (via ls_id) to obtain the aperture fluxes and inverse variances (apflux_*_1 .. apflux_*_8, apflux_ivar_*_1 .. apflux_ivar_*_8) that the adaptive flux calculation needs.

References#

  • Astro Data Lab documentation: the service, the datalab command line tool and the mydb and query interfaces.

  • Koposov & Bartunov 2006: the q3c sky-indexing that q3c_join / q3c_radial_query use.

  • The catalog columns are described in the pages of each survey (Legacy Survey (optical), VISTA Hemisphere Survey (VHS), UKIDSS (near-infrared), Euclid Q1 (optional)).
